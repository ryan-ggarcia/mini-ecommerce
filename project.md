## Projeto do mini-ecommerce

## funcionalidades
-   Criar uma plataforma online onde sera permitido a venda de produtos
locais como frios, doces, sapatos e etc... entregado com o Whatsapp

## O que o sistema precisa ter
-   Cadastro de produtos com foto, preco, descrição e estoque
-   Recebimento de pedidos com notificação
-   Integração com Pix
-   Relátorio de venda
-   Controle de usuários 
-   Listagem de usários e produtos

## Para o comprador
-   Catálogo de visual dos produtos
-   Carrinho e finalização de pedido
-   Pagamento via Pix ou na entrega
-   Acompanhamento do status do pedido

## Fluxo do sistema de compra
-   Cliente acessa o catálogo
==> Monta o carrinho
-   Cliente escolhe forma de pagamento 
==> PIX e etc...
-   Sistema gera qrcode 
-   Sistema manda uma mensagem para o Vendedor
==> Mostrando Nome e informações do Cliente
-   A compra vai para acompanhamento de confiamção de compra
==> Cliente confirma forma de pagamento 
-   Sistema atualiza o status da compra e estoque 
==> Sistema confirma o pedido e manda uma mensagem para o cliente 
-   Sistema gurda registro de compra
